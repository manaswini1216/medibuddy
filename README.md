# Medicine Search

A simple medicine search application built with Next.js, TypeScript and the FDA Drug Label API.

## Features

- Search medicines by brand name
- Display medicine details like brand name, generic name, manufacturer, product type and route
- Dedicated medicine details page
- Loading, error and no-results states
- Recent search suggestions
- Cached search results to avoid repeated API calls
- Request cancellation for older searches
- Responsive design for desktop and mobile
- Handles missing API fields safely

## Tech Used

- Next.js
- TypeScript
- React
- CSS
- FDA Drug Label API
